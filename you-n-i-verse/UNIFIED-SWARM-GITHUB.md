# Synthia Unified Swarm GitHub integration

**Version:** 0.1.2 (binary 3–2–1, provisional semantic mappings).

This additive GitHub integration installs preserved original SWARM-OS Pass 05, Synthia Consciousness Swarm and neural-composition sources under `you-n-i-verse/unified-swarm/`. The existing Simlish world and its linked Generative-address-system assembly remain unchanged. The original ZIP and checksum are retained as provenance.

The 3, 2, and 1 levels each contain that many independent 0/1 slots. The grouping for Color/Tone/Base, Line, and Axis/House is explicitly provisional where its semantic assignment is unresolved. The structural 3–2–1 view is not conflated with the Zhouyi hexagram view or biological codon chemistry. No binary meanings are silently derived from personal chart coordinates.

**CI:** SHA-256-checks the archive, expands all preserved JS sources, executes 19 unit tests, runs the actual Synthia/Simlish handoff test, and publishes expanded sources on the integration branch. No tracked original sources are deleted. Separate runtime remains a Node/JS adapter, not an Android-complete morphing computer.
