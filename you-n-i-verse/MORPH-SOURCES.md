## Implemented controls

Face sculpt applies regularized radial scaling, changing the actual warp geometry.

## Validation

Three geometry regression checks plus existing triangle and library checks pass.
Headless Chromium ran the actual bundled face-landmarker with a public OpenCV
portrait fixture: 468 landmarks, approximately 900 triangles, finite output and
65,011 changed color channels between default and sculpted outputs; no page errors.
This proves a visible 2D deformation path, not arbitrary anatomical generation.
3D reconstruction, generated forms and upstream animation adapters remain pending.
