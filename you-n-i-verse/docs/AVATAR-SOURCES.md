# Reusable avatar and motion sources reviewed

These components address different stages. Only Three.js and its credited demonstration rig are bundled in this update. The supplied state-space meanings remain in the existing sentence/path modules; none of the graphics repositories replaces those rules.

## This build

Photo studio and game remain available. A separate `rig.html` page demonstrates real continuous rig animation and expression targets, imports self-contained GLB files under 32 MiB, saves the rig locally, and renders 12 poses (4×3) into a sprite sheet. The sheet can be transferred into the studio for playback or further face morphing. External textures and compressed-model decoders are intentionally not fetched during import.

An optional photo surface uses the saved studio portrait. Its 468 landmark vertices, UV coordinates and estimated relative depth create a front-facing textured surface attached to a named Head bone. It is a limited experiment, not a complete human reconstruction or a trained identity-transfer model. It needs head geometry attached beneath that bone; rigs with separate skinned head bindings need a specific adapter. It does not invent side/back/hair detail or inherit existing facial expression shapes. The named head binding survives reload, using the latest saved portrait. It is included in exported sheets.

No backend/API key is used. The 3D preview requires WebGL; the existing local CPU photo/sprite path remains separate. No new neural model was trained. No user or public test portrait is bundled in the app. The existing state-space rules were not replaced with rig names, hash-derived chart coordinates, or arbitrary graphics-library semantics.

## Verification

Node checks validate local GLB resource boundaries and the real demo's skeleton/animation/morph data. Chromium tests check clip playback, pause, expressions, speed persistence, PNG export, studio transfer, photo head binding and reload. Browser runtime tests recorded zero off-origin requests. Physical Android device rendering remains unverified.
