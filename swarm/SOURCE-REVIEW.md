# Supplied-source review

## Coverage and reading limits

All sixteen supplied source pieces were downloaded, hashed and unpacked. Twenty-five embedded archives were also expanded. The file inventory accounts for **5,344 file paths**, **2,646 distinct byte contents**, **5,037 UTF-8-readable paths**, and **307 binary paths**.

`review/files.json` contains every relative path, size, SHA-256, text/binary classification, duplicate reference and indexed topic. This is an inventory and machine-assisted source scan, not a claim that every line of every dependency or every page of every book has been read and understood. The implementation paths below were directly inspected. PDF extraction coverage is recorded separately. Generated/minified bundles, historical snapshots and compiled binaries remain preserved evidence rather than proposed active source.

## Directly inspected mechanisms

- Foundation constructor/apply/transact: journal landed before acknowledgement; restoration replays inputs; lineage and fit share consequences with the existing mesh.
- ATO Automaton/AutomataMesh: independently callable implementations, owned state, typed/versioned ports, required/guaranteed invariants, compatible connection checks, bounded mesh runs and explicit recursive termination.
- Pure Synthia operators: ordered sequence, unordered bundle, recursion, transformation, discourse and bit-level changes preserve derivations at different scales.
- EmergentChannels: recorded packet crossings promote to sequential capabilities after a configured threshold. This is an actual cultivation mechanism; usage threshold is a donor parameter, not a proven universal law.
- Character Need/ActivityChooser: need depletion/satisfaction, drive, movement to usable activities, emotion updates and health consequences. Unity time, navigation and random selection require explicit adaptation.
- Cynthia persistent room agent: task queue, skills/capabilities, location/activity and evidence-derived development. It is a separate visible shell over state; it currently trims its history after 500 events.
- CodonLife AutonomousAgent/GeneticService: energy/behavior/skill/memory and crossover donor paths contain random choices. They cannot silently become deterministic source-defined particle laws.
- RuntimeBridge: demands/gaps normalize into capability needs; outcome adapters feed ScienceMode, SuccessAutomaton and mesh. Missing adapters return explicit unavailable states.
- Sound/address/primitive-attribution paths: source contains real render descriptors, but several conventions conflict with current requirements.

## Conflicts and incomplete paths

1. Foundation donor addressing uses absolute wheel degrees and eight houses in one codec; user DMSA uses local degree 0–29 and the wider address context. One supplied constants document also uses 99 arc units indexed 0–98, while the user-facing arc contract is 0–99. Conversion must be explicit; defaults/modulo cannot validate user input.
2. Donor phonological hypothesis maps all vowels to Being and nasals to Space. User vowel primitives are I/Movement, A/Evolution, E/Being, U/Design, O/Space; M is Matter within Being. Hypothesis data must remain distinct from those user rules.
3. Donor sound rules use 432 Hz, scale/timbre/duration tables and fallback dimension/zodiac/address values. They are donor conventions, not recovered proof of the binary-to-sound rule or the required live address filter.
4. Several donor systems expose five peer stages or field counters. Space must remain an emergent expression in the contributing-field architecture, even when a five-perspective view is useful. The supplied constants document swaps Movement/Where and Being/When; the user's rule is Movement/When and Being/Where.
5. Native mesh execution and generated media exist; authoritative host-game causation and source-grounded particle morphology are not yet one connected runtime.
6. Crossover exists in CodonLife; a complete phase-separated GA/PSO runtime was not established by the reviewed paths.
7. Character random actions, wall-clock identifiers and history truncation require deterministic/evidence-preserving adapters where the current contract demands them.
8. The newly added physics demonstration has unaddressed particles, fixed bit colors, sample flavors, authored bond rules and no host game adapter. Passing its five tests does not establish full system completion.
